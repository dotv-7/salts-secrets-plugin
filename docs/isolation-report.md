## Coverage and limits

- The platform APIs are stand-ins on loopback, not live Telegram or Discord: the adapters, the gateway, routing, authorization, the agent loop and the plugin are the real code; the network peer is not.
- The model is a scripted fake. It proves what reaches the model provider, not how a real model phrases a refusal.
- Owner-side classify/draft calls (the dashboard asking the model to sort and rewrite items) are not exercised here; they run in the owner profile and never on a guest's behalf.
- Compression/summary calls only occur in long conversations; this run is two turns per chat, so the auxiliary calls recorded are mostly title generation.
